# Aftermark

Evidence-driven incident response API built with TypeScript, Fastify, Bun, and Zod. Cloudflare D1 stores application data via its REST API; the server runs on a Bun-capable host, not Cloudflare Workers/Pages.

## History provenance

The 16 implementation commits use assigned historical timestamps on October 28–29, 2026 (UTC), eight commits per day, at the repository owner's request. Those dates are organizational metadata, not a record of when development actually occurred. The inherited scaffold commit predates this implementation.
